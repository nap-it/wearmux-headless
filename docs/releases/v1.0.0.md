This is the initial research release of **WearMux Headless**, the Node.js host accompanying the manuscript *WearMux: Real-Time Multimodal Sensing and Feedback across Heterogeneous Wearables*.

Headless connects compatible wearable devices through the Brilliant Wear JavaScript SDK and exposes their available sensing and feedback capabilities to command-line tools, local consumers, and distributed applications.

## Included in this release

- Capability-based device sessions, concurrent connections, configuration, and reconnection handling.
- Bluetooth Low Energy connectivity and configured Wi-Fi WebSocket/UDP connections where supported by the device firmware.
- Camera acquisition, local recording, and an MJPEG viewer; microphone monitoring, recording, and streaming; sensor acquisition with configurable stream selection and rate limits.
- Supported display and haptic feedback, including bitmap color-depth reduction and MTU-aware tiling.
- Local consumers and MQTT/Zenoh messaging, with a Python Zenoh bridge and a reverse path for application actions.
- Command-line inference tools and separate Whisper and YOLO consumer examples. These optional consumers are outside the core container image.
- Configuration guides, integration and message-contract documentation, and a generated JSDoc API reference.

## Container images

The release pipelines publish images for **Linux AMD64 and ARM64**.

```bash
docker pull ghcr.io/nap-it/wearmux-headless:v1.0.0
```

Bluetooth operation requires access to the host's adapter and BlueZ configuration; network operation requires compatible device firmware and transport settings. See the deployment guide before running the container.

## Research scope

Device capabilities depend on the hardware, firmware, SDK, permissions, and connection settings. The Headless host supports SDK-compatible devices; phone sensors and Wear OS integration are provided by the separately maintained [WearMux Android host](https://github.com/nap-it/wearmux-android/releases/tag/v1.0.0).
